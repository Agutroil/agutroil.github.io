01 / Game overview

One world.
Many adventurers.

Nythara is a 2D MMORPG inside a stylized 3D fantasy world. Follow authored trails, fight readable enemies, build a persistent character and meet other players in the online multiplayer alpha.

Hand-built regions, portals, cities and dungeon paths with a clear sense of place and a world map to match.

⚔

Fight

Telegraphed attacks, active skills, status effects and multi-phase bosses built around readable real-time combat.

✦

Progress

Levels, attributes, skill ranks, equipment and loadouts on one persistent character that carries between sessions.

🌐

Connect

Online multiplayer alpha with a shared server-authoritative world, chat, trading and dungeons for connected players.

07 / Online multiplayer alpha

A shared world,
run by the server.

Nythara's online multiplayer alpha connects independent players in one shared, server-authoritative world, with remote play, persistent characters and reconnect support.

Characters, movement, combat, enemies, loot, progression and world state are controlled by the server and synchronised between connected players.

Meet other adventurers in Silverwood, fight the same creatures, talk in local chat and trade items. Characters return after a reconnect or server restart.
